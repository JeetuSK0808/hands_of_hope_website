# Hands of Hope

The official website for Hands of Hope, a 501(c)(3) student-led nonprofit.

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Stack

- Next.js (App Router)
- Tailwind CSS v4
- shadcn/ui
- GSAP for scroll animations
